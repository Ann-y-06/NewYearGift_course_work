# 🎁 Конструктор Новорічного Подарунка (New Year Gift App)

Повноцінний десктопний застосунок на **JavaFX** для управління складом солодощів та формування дитячих новорічних подарунків. Проєкт реалізовано з використанням сучасних архітектурних патернів, бази даних SQLite та покритий модульними й UI тестами (90%+).

---

## 📋 Основний функціонал

### 🏭 Керування складом (База даних SQLite)
* **Візуалізація:** Зручне відображення повного списку солодощів у графічному інтерфейсі.
* **Додавання:** Створення нових об'єктів (Цукерка, Шоколад, Вафля) через спеціальні форми з динамічними полями та валідацією.
* **Імпорт з CSV:** Можливість масового завантаження нових товарів із файлів `.csv` із захистом від дублікатів та помилок парсингу.
* **Видалення:** Вилучення окремих товарів або автоматична очистка складу від прострочених солодощів.

### 🎁 Робота з подарунком
* **Формування:** Інтерактивне додавання солодощів зі складу (з вибором кількості).
* **Розрахунок:** Автоматичний підрахунок загальної ваги та вмісту цукру.
* **Генерація чека:** Формування та збереження святкового чека у форматі `.txt` із детальною статистикою подарунка.

### 🔍 Аналіз та Пошук (Stream API)
* **Сортування:** За вагою або за вмістом цукру.
* **Пошук:** За назвою, за виробником або за точним діапазоном вмісту цукру (за допомогою інтерактивних повзунків).

### 🚨 Система сповіщень
* **Автоматичні репорти:** У разі виникнення критичних збоїв система генерує звіт та відправляє його на вказану електронну пошту (через JavaMail API).

## 🛠 Технології та Інструменти

* **Мова:** Java 17+
* **GUI Фреймворк:** JavaFX (з використанням FXML та кастомних CSS стилів)
* **База даних:** SQLite (JDBC)
* **Збірка проєкту:** Maven
* **Мережа:** JavaMail API (відправка email)
* **Тестування (Coverage 90%+):** JUnit 5, Mockito, TestFX (для тестування графічного інтерфейсу), Jacoco (аналіз покриття).

---

## 🏗 Архітектура (MVC + Repository)

Проєкт побудований за принципами чистої архітектури з чітким розділенням відповідальності:

* **Model:** Об'єктно-орієнтована ієрархія класів (`Sweet` -> `Candy`, `Chocolate`, `Waffle`) з інкапсуляцією та поліморфізмом.
* **Repository:** Патерн для взаємодії з базою даних SQLite (`DatabaseManager`, `DatabaseSweetRepository`).
* **Service:** Бізнес-логіка програми, яка ізольована від інтерфейсу (`GiftServiceImpl`).
* **UI (Controllers):** Графічні контролери JavaFX, що відповідають виключно за відображення даних та обробку дій користувача.
