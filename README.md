# 🎁 Конструктор Новорічного Подарунка (New Year Gift)

Консольний додаток на Java для управління складом солодощів та формування дитячих новорічних подарунків. Проєкт реалізовано в рамках курсу "Прикладне програмування" (Лабораторні роботи №4-6).

## 📋 Функціонал

### 🏭 Керування складом (База даних)
* **Перегляд:** Відображення повного списку солодощів.
* **Додавання:** Створення нових об'єктів (Цукерка, Шоколад, Вафля) з валідацією введення.
* **Видалення:** Вилучення товарів зі списку.
* **Контроль якості:** Автоматичний пошук та видалення прострочених товарів.
* **Збереження даних:** Автоматичне збереження стану складу у файл `sweets.csv` (з підтримкою автозбереження).

### 🎁 Робота з подарунком
* **Формування:** Додавання солодощів зі складу у поточний подарунок.
* **Розрахунок:** Автоматичний підрахунок загальної ваги подарунка.
* **Редагування:** Видалення позицій із подарунка.

### 🔍 Аналіз та Пошук
* **Сортування:**
  * За вагою (від найлегшої).
  * За вмістом цукру (від найменшого).
* **Пошук:**
  * За назвою.
  * За виробником.
  * За діапазоном вмісту цукру (мін/макс).

## 🛠 Технології та Архітектура

* **Мова:** Java (JDK 17+)
* **Формат даних:** CSV (Comma-Separated Values)
* **Патерн проєктування:** **Command** (Команда) — для організації меню та відділення інтерфейсу від бізнес-логіки.
* **OOP:** Використання успадкування (`Sweet` -> `Candy`, `Chocolate`, `Waffle`), поліморфізму та інкапсуляції.
* **Java Stream API:** Використовується для ефективної фільтрації, сортування та пошуку даних.
